# Inventário de repositórios Wazuh

**34 referências** conferidas quanto à existência, classificadas por domínio funcional e tipo de artefato. A conferência de README foi feita quando indicada no CSV; nenhum projeto externo foi executado.

| Campo do CSV | Uso |
|---|---|
| `repository` e `url` | Nome completo e URL canônica do mantenedor |
| `primary_domain` | Categoria editorial principal; itens podem participar de outras áreas |
| `artifact_type` | Código, integração, configuração, guia, lab, histórico ou fonte oficial |
| `tier` | A (essencial), B (complementar), C (contextual) |
| `verification` | `repo_confirmado` ou `repo_confirmado_readme` |
| `curation_note` | Alerta ou restrição relevante para seleção |
| `checked_on` | Data da conferência documental, não de avaliação técnica |
